# The file-open ledger: one row per call in the non-test tree that opens,
# makes, removes, renames, walks, lists or runs something by a path, and
# where that path came from. The test beside this file finds every such
# call and holds this file to it: a call with no row, a row with no call,
# a key twice, rows out of order, and a network row naming a rule that is
# not a function in the tree each fail it. A row is
#
#   <file> <enclosing function> <callee>(<path argument as written>) = <provenance>
#
# and the provenance is one of:
#
#   local      a path this program made from its own constants, its home
#              and names it generated (a random temporary name, an id
#              from envelope.NewID);
#   operator   a path the person running the program typed or configured:
#              a flag, a config file's setting, a relay name they chose
#              (held to the export-line rule by ValidRelayName at
#              AddRelay), a file they named;
#   derived:   a path made from something this program read back from its
#              own files or environment, said what; an entry of a
#              directory it owns, a record it wrote, os.Executable;
#   network:   a path with a component that arrived over the wire, naming
#              the component, the rule that checks it and the point it
#              runs at; the rule is a function in the tree, or, for a
#              component whose rule is its type (a number the JSON
#              decoder holds to a number), the standard-library function
#              that writes the value, such as strconv.FormatInt. Where a
#              path has components of several kinds the row names the
#              least trusted, and a helper's row names the least trusted
#              of its callers' paths.
#
# The rule is the development guide's: what a peer names is never a path
# until its rule has run. A new call that opens something by a path fails
# the test until its row is here, which is the point.
