# The file-open ledger: one row per call in the non-test tree that opens,
# makes, removes, renames, walks, lists or runs something by a path, and
# where that path came from. The test beside this file finds every such
# call and holds this file to it: a call with no row, a row with no call,
# a key twice, rows out of order, a network row naming a rule that is not
# a function in the tree, and a row that is not local and names no test
# each fail it. A row is
#
#   <file> <enclosing function> <callee>(<path argument as written>) = <provenance> [shown by <TestLimit>]
#
# and the provenance is one of:
#
#   local      a path this program made from its own constants, its home
#              and names it generated (a random temporary name, an id
#              from envelope.NewID); no test, since nothing from outside
#              is in it;
#   operator   a path the person running the program typed or configured,
#              in one of three forms:
#                operator's absolute path
#                   a whole path used as given, alone or under the
#                   program's own constant names: a flag, a file they
#                   named on the command line; no test, since nothing is
#                   joined onto it;
#                operator: <setting> in <file>, resolved against <base>
#                   a value from a configuration file, which is relative
#                   to that file's directory and never to the working
#                   directory the program happened to start in, with the
#                   test that shows the resolution;
#                operator: <name>, <rule> at <point>
#                   a name they chose that is joined under a directory,
#                   such as a relay name under relays/, with the rule that
#                   makes it one segment, the point it runs at, and the
#                   test that drives the traversal set through it;
#   derived:   a path made from something this program read back from its
#              own files or environment, said what: an entry of a
#              directory it owns with the rule the reader holds the entry
#              to and the test that feeds the reader strays; a record it
#              wrote with the rule at the read; or, for the runtime
#              directory and os.Executable, "the environment's own path",
#              which has no test since nothing is joined onto it;
#   network:   a path with a component that arrived over the wire, naming
#              the component, the rule that checks it and the point it
#              runs at, and the test that drives the traversal set
#              through the rule; the rule is a function in the tree, or,
#              for a component whose rule is its type (a number the JSON
#              decoder holds to a number), the standard-library function
#              that writes the value, such as strconv.FormatInt. Where a
#              path has components of several kinds the row names the
#              least trusted, and a helper's row names the least trusted
#              of its callers' paths.
#
# A name from outside — a network row, or a derived row that is an entry
# of a directory read back — is opened or created through internal/regular
# (regular.Open, Create, OpenFile, ReadFile, Dir), which asks the handle
# what it is and refuses a device, a pipe, a socket, a link or a
# directory under any name; a row of either kind whose callee is the
# plain os.Open, OpenFile, Create, WriteFile or ReadFile fails the test.
# Such a name is never a rename's destination either, since a rename has
# no handle to ask: a rename row of either kind whose argument is the
# destination ends with "; the last name is the program's own" or "; the
# last name is an id", saying that only the directory is from outside, or
# fails. The operator's own input files are not held to this: a
# passphrase file from process substitution is a pipe on purpose.
#
# The rule is the development guide's: what a peer names is never a path
# until its rule has run, and the testing guide's: the rule is shown by a
# test that feeds it the traversal set. A new call that opens something by
# a path fails the test until its row is here, which is the point.
