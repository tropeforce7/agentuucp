# The limit ledger: one row per place in the non-test tree where an
# integer or a time from outside enters the program, a string is cut, or
# a reader is capped, and the range the code holds it to, or that it is
# open, and the TestLimit test that shows the edge and one step past. The test beside this file finds every such place and
# holds this file to it: a site with no row, a row with no site, a key
# twice, a range of no known shape, a test not declared exactly once, a
# test not named TestLimit, and an output row for a struct the program
# decodes each fail it. A row is
#
#   <file> <enclosing function or struct> <kind> <site as written> = <range> shown by <TestLimit...>
#
# where the kind is int, string, cap or time. An int site is a field of integer,
# duration or integer-valued map or slice type in a struct with a json
# tag, wherever the struct is declared; a strconv.Atoi or Parse*; a
# time.ParseDuration; a binary.*.Uint* read; a FlagSet's integer or
# duration method. It is written as the field with its type, or the
# callee with its first argument, and its range is one of
#
#   [lo, hi]       a closed interval, in the field's unit
#   >= n, > n      a floor, <= n, < n a ceiling; a duration's bound
#                  carries its unit, as >= 5s
#   0 or ...       zero is a sentinel the range does not otherwise hold:
#                  the default, or unlimited
#   one of a, b    a set, such as an ML-DSA parameter set
#   open           no bound but the type's; the test shows a negative
#                  refused before the value is used
#   output         a struct the program writes and never decodes, which
#                  the test proves; no test is named
#
# A string site is a slice expression on a string or a byte slice,
# whatever its bound (the second trace's panic was a constant [:16] on a
# two-byte fingerprint), or on another slice with a bound that is not a
# constant. It is written as the expression, and says one of
#
#   local: <Rule> at <point> shown by <TestLimit...>
#                  the rule that fixed the operand's length and the
#                  point it ran; the rule is a function in the tree, and
#                  the test, one per rule and shared, feeds the operand
#                  one byte short at that point
#   local: <why>   the operand's own arithmetic: a length the code
#                  checked, an index a loop or Index gave, a rune
#                  boundary; names no test
#   <why> shown by <TestLimit...>
#                  a cut with no rule upstream, shown by its own test
#
# A cap site is a reader bounded by http.MaxBytesReader or io.LimitReader,
# written as the callee with the reader and the bound, or a header cap set
# on an http.Server or an http.Transport, MaxHeaderBytes or
# MaxResponseHeaderBytes, written as the field and its value (with the
# receiver when set by assignment). Its row says the bound as the site
# reads under it — a reader bounded one over its route's hold, so that an
# answer over the hold is known to be over it, says the hold plus one —
# and is one of
#
#   <= n           the bound; where the site's bound is a constant the
#                  test holds n to it, and where it is not, n is the
#                  name the code gives it with its arithmetic, as
#                  "hold + 1", held to the code's spelling. A name that
#                  reads a parameter or a local is refused unless the
#                  test names the site as an exception, with why
#   one of a, b    the bound is a parameter and the callers give it
#                  these. The test follows the parameter to every caller
#                  in its package, and through a caller's own parameter
#                  to that caller's callers. It reads a constant by its
#                  value and a method by the test's table of bounds.
#                  Every value passed must be listed, and every value
#                  listed passed. A function that is exported, used other
#                  than in a call, called through an interface or as a
#                  method expression, named in a file the build leaves
#                  out, or never called cannot give a list, and neither
#                  can a caller that spreads another call's results
#   local: <why>   the bound is the program's own arithmetic on values
#                  it already holds, with no edge from outside to feed;
#                  the why says which values, and the row may name the
#                  test of what made them equal
#
# and names the TestLimit test that feeds the reader at the bound and one
# over.
#
# A time site is a field in a struct with a json tag, tagged or not, of a
# type that holds a time: time.Time, a struct embedding one, a type
# defined over it (which the decoder cannot read from a string, but which
# holds one), or a pointer, slice, array or map of these, a map by its key
# too, written as the field; or a time.Parse or time.ParseInLocation, written
# as the callee with the value it parses.
# Its row is one of
#
#   <= now + 5m    a stamp held to no more than relayapi.MaxSkew ahead of
#                  the reader's clock, the one bound a stamp has; its test
#                  feeds the edge and a second either side, a day and a
#                  year ahead, a year past, and the earliest and latest
#                  instants: through the reader where the wire can carry
#                  them, and to the encoder, which refuses them, where it
#                  cannot
#   [lo, hi]       a window with both edges, named as the code names them
#   deadline: <its use>
#                  a time that names a moment to come, compared with now,
#                  with the other edge of its own window or with an
#                  earlier copy of itself, or for the earliest to show,
#                  never ordered across
#                  records, and written to a file only as a record of it
#                  that orders nothing; its test feeds the earliest instant
#                  and one past year 9999, through the code that uses it
#                  where the wire can carry them, and shows no panic and
#                  no overflow
#   display        shown and never compared or ordered: the test refuses
#                  the row when the field, or a time derived from it by a
#                  method of time.Time, a dereference or an index, is an
#                  operand of Before, After, Equal, Sub or Compare, of
#                  time.Since or time.Until, or a side of a comparison (a
#                  pointer, slice or map held against nil excepted), or
#                  is read in a comparator written in the call that sorts
#                  or in a Less method, anywhere in the tree. That is not
#                  every way to compare a time, and the row is read
#                  against its field for the rest: among them a copy into
#                  a local, or into a struct with no row; a comparison
#                  through Unix or UnixNano; a defined type converted back;
#                  a method promoted from an embedded time; a helper of the
#                  tree's own that compares what it is handed; a whole
#                  struct compared; a comparator held in a variable; a file
#                  the build leaves out. Names no test
#   output         a struct this program writes and never decodes
#   local: <why>   this program's own clock or its user's own input read
#                  back, or a value a check already held, the why saying
#                  which; needs no test, and one it names is held to
#                  being a TestLimit test
#   unbounded: PLAN-TIME commit N
#                  a stamp from outside the plan bounds in its commit 2
#                  or 3, until then; names no test, and goes with the
#                  plan's commit 3
#
# The sweep that wrote this file found 285 sites, and the cap kind added
# twelve. The walk had found 454 by the time the time kind added 88; 542
# is the floor in the test.
