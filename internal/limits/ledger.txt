# The limit ledger: one row per place in the non-test tree where an
# integer from outside enters the program, and the range the code holds
# it to, or that it is open, and the TestLimit test that shows the edge
# and one step past. The test beside this file finds every such place and
# holds this file to it: a site with no row, a row with no site, a key
# twice, a range of no known shape, a test not declared exactly once, a
# test not named TestLimit, and an output row for a struct the program
# decodes each fail it. A row is
#
#   <file> <enclosing function or struct> <kind> <site as written> = <range> shown by <TestLimit...>
#
# where the kind is int, string or cap. An int site is a field of integer,
# duration or integer-valued map or slice type in a struct with a json
# tag, wherever the struct is declared; a strconv.Atoi or Parse*; a
# time.ParseDuration; a binary.*.Uint* read; a FlagSet's integer or
# duration method. It is written as the field with its type, or the
# callee with its first argument, and its range is one of
#
#   [lo, hi]       a closed interval, in the field's unit
#   >= n, > n      a floor, <= n, < n a ceiling; a duration's bound
#                  carries its unit, as >= 5s
#   0 or ...       zero is a sentinel the range does not otherwise hold:
#                  the default, or unlimited
#   one of a, b    a set, such as an ML-DSA parameter set
#   open           no bound but the type's; the test shows a negative
#                  refused before the value is used
#   output         a struct the program writes and never decodes, which
#                  the test proves; no test is named
#
# A string site is a slice expression on a string or a byte slice,
# whatever its bound (the second trace's panic was a constant [:16] on a
# two-byte fingerprint), or on another slice with a bound that is not a
# constant. It is written as the expression, and says one of
#
#   local: <Rule> at <point> shown by <TestLimit...>
#                  the rule that fixed the operand's length and the
#                  point it ran; the rule is a function in the tree, and
#                  the test, one per rule and shared, feeds the operand
#                  one byte short at that point
#   local: <why>   the operand's own arithmetic: a length the code
#                  checked, an index a loop or Index gave, a rune
#                  boundary; names no test
#   <why> shown by <TestLimit...>
#                  a cut with no rule upstream, shown by its own test
#
# A cap site is a reader bounded by http.MaxBytesReader or io.LimitReader,
# written as the callee with the reader and the bound, or a header cap set
# on an http.Server or an http.Transport, MaxHeaderBytes or
# MaxResponseHeaderBytes, written as the field and its value (with the
# receiver when set by assignment). Its row says the bound as the site
# reads under it — a reader bounded one over its route's hold, so that an
# answer over the hold is known to be over it, says the hold plus one —
# and is one of
#
#   <= n           the bound; where the site's bound is a constant the
#                  test holds n to it, and where it is not, n is the
#                  name the code gives it with its arithmetic, as
#                  "hold + 1"
#   one of a, b    the bound is a parameter and the callers give it
#                  these
#   local: <why>   the bound is the program's own arithmetic on values
#                  it already holds, with no edge from outside to feed;
#                  the why says which values, and the row may name the
#                  test of what made them equal
#
# and names the TestLimit test that feeds the reader at the bound and one
# over.
#
# The sweep that wrote this file found 285 sites, and the cap kind added
# twelve; 297 is the floor in the test.
