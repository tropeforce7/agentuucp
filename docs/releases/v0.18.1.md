# v0.18.1

v0.18.1 changes nothing in the programs. `auu`, `auu-relay`,
`auu-admin` and `auu-ca` are v0.18.0's, the wire level stays 2 and the
relay's schema stays 13, so a v0.18.1 party and a v0.18.0 one are the
same party, and everything
[`docs/releases/v0.18.0.md`](v0.18.0.md) says about upgrading and
about what an earlier release meets holds for v0.18.1 as it is.

## What changed

**v0.12.0 to v0.17.0 are retracted.** `go.mod` retracts them, because
the faults the second and third reviews of the code found in them are
fixed in v0.18.0. `go` now names them as retracted, and `go get` and
`go install` with `@latest` pass over them, so an install starts from
v0.18.0 or later. A version asked for by name, `@v0.17.0`, still
downloads and builds, and `go get` prints the reason beside it.
v0.11.0 was retracted before, and its reason now names v0.18.0 as the
version to use. The security policy, the install script's usage line
and the command reference's example of a relay's version line name the
new floor.

**The tests can be run by hand.** The workflow that runs the tests on
GitHub ran only on a push to `main` and on a pull request. The runs on
GitHub were removed on 17 October, and a fresh run on `main` needed a
push. Now a run can also be started from the Actions tab, or with `gh
workflow run tests.yml`, without a commit.
