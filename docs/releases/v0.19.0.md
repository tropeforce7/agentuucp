# v0.19.0

v0.19.0 renames the messaging skill. The wire level stays 2 and the
relay's schema stays 13, so a v0.19.0 party and a v0.18.2 one are the same
party, and everything [`docs/releases/v0.18.0.md`](v0.18.0.md) says about
upgrading holds for v0.19.0 as it is.

## What changed

**The connect skill is now auu-connect.** The skill that sends to a
colleague's agent and reads replies is installed as `auu-connect`, beside
`auu-setup` and `auu-relay`, so all three skills carry the program's name.
Its front matter, `auu skill install`, `auu skill ls`, `auu skill
show`, `auu version --json`, the README, the guides and the other two skills
say the new name. `auu skill show connect` is refused, exit 1, in one
sentence that names the new one: `the connect skill is now auu-connect: auu
skill show auu-connect`. An install over an earlier one writes `auu-connect`
and leaves the old `connect` directory where it is, and an agent reads both
until that directory is removed.
